## Overview

NullSec Windows is an exclusive security toolkit built specifically for Microsoft Windows systems using native languages and APIs.

## Languages Used

| Language | Purpose | Why |
|----------|---------|-----|
| **C#** | Main toolkit | Native .NET with full Windows API access |
| **F#** | Functional analysis | Type-safe security analysis tools |
| **PowerShell** | Automation | Deep Windows integration |
| **Batch** | Legacy support | Quick scripts for older systems |

## Features

### 🔐 Security Analysis
- Windows Defender status checker
- BitLocker encryption analyzer
- Windows Firewall auditor
- UAC configuration inspector
- Secure Boot status checker

### 🛡️ Network Security
- Active connections monitor
- Port scanner
- DNS cache analyzer
- SMB share auditor

### 💻 System Security
- Registry security scanner
- Service configuration auditor
- Scheduled task analyzer
- Startup item inspector

### 🔍 Forensics Tools
- Event Log analyzer
- Prefetch file parser
- Browser artifact extractor (Premium)

## Installation

```powershell
git clone https://github.com/bad-antics/nullsec-windows.git
cd nullsec-windows
dotnet build -c Release
```
